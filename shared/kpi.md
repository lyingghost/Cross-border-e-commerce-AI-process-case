# 指标字典

统一口径，避免两个 Agent 算出不同的"利润"。

## 单位与经济指标

| 指标 | 定义 | 公式 | 目标（参考） |
|---|---|---|---|
| **GMV** | 成交总额 | 订单金额合计（含退款前） | — |
| **净销售额** | 扣除退款后的实际销售额 | GMV − 退款额 | — |
| **单件毛利** | 扣掉直接与履约成本 | 售价 − 货值 − 头程 − 平台佣金 − 履约费 − 包装 | ≥ 30% 售价 |
| **单件净利** | 再扣广告与间接成本 | 单件毛利 − 单件广告费 − 退货损耗 − 支付/汇兑损失 | ≥ 15% 售价 |
| **毛利率** | — | 单件毛利 ÷ 售价 | ≥ 30% |
| **净利率** | — | 单件净利 ÷ 售价 | ≥ 15% |
| **ROI** | 投入产出比 | 净利润 ÷ 总投入 | ≥ 1.5 |
| **回本周期** | 投入全部收回所需天数 | 累计净利 ≥ 累计投入的首日 | ≤ 90 天 |

### 成本项清单（算单件净利时逐项核对）

```
货值（含税出厂价）
+ 国内物流（供应商 → 集货仓）
+ 头程（国际运费，按体积重或实重取大）
+ 关税 / 进口增值税（按目的国税率）
+ 平台佣金（按类目，通常 5%–20%）
+ 履约费（FBA / 平台仓 / 自发货邮费）
+ 包装与贴标
────────────────
= 落地成本

落地成本
+ 仓储费（长期仓储另计）
+ 广告费（单件分摊 = 广告花费 ÷ 成交件数）
+ 退货损耗（退货率 × 单件不可回收损失）
+ 支付手续费 / 汇兑损失（约 2%–4%）
────────────────
= 单件总成本

售价 − 单件总成本 = 单件净利
```

> **常见坑**：忘记算退货损耗和汇兑损失。这两个加起来经常吃掉 5–8 个点。

## 广告指标

| 指标 | 公式 | 说明 | 目标 |
|---|---|---|---|
| **ACOS** | 广告花费 ÷ 广告带来的销售额 | 只看广告归因的订单 | 冷启动 ≤ 60%，稳定期 ≤ 30% |
| **TACOS** | 广告花费 ÷ 总销售额 | 含自然单，更能反映健康度 | ≤ 15% |
| **ROAS** | 广告带来的销售额 ÷ 广告花费 | ACOS 的倒数 | ≥ 3 |
| **CTR** | 点击 ÷ 曝光 | 反映主图/标题 | ≥ 0.4%（站内），≥ 1%（信息流） |
| **CVR** | 订单 ÷ 点击 | 反映 Listing/落地页 | ≥ 10%（站内），≥ 2%（短视频） |
| **CPC** | 广告花费 ÷ 点击 | — | 越低越好，但要看质量 |

## 库存与履约

| 指标 | 公式 | 目标 |
|---|---|---|
| 可售天数 | 当前库存 ÷ 近 7 日均销量 | ≥ 30 天，< 14 天触发 `stock.low` |
| 库存周转率 | 期间销货成本 ÷ 平均库存 | 越高越好 |
| 断货天数 | 库存为 0 的天数 | 0 |
| 退货率 | 退货件数 ÷ 成交件数 | ≤ 类目均值 |

## 客户指标

| 指标 | 公式 | 目标 |
|---|---|---|
| 好评率 | 4–5 星评价数 ÷ 总评价数 | ≥ 90% |
| 差评率 | 1–2 星评价数 ÷ 总评价数 | ≤ 5% |
| 复购率 | 90 天内复购客户数 ÷ 总客户数 | 视品类 |
| 客服首响时长 | — | ≤ 12 小时（平台考核） |

## 团队效率指标（这套系统好不好用，看这两个）

| 指标 | 定义 | 目标 |
|---|---|---|
| **人时产出** | 每周 GMV ÷ 投入人时 | 逐月上升 |
| **Agent 净收益** | Agent 节省的人时 − 与 Agent 协作花的人时 | > 0，否则精简 Agent |

> 每月算一次。如果某个 Agent 的净收益连续两月为负，停用它或重写它的 SOP。

## 口径约定

1. **货币**：对外售价用当地货币，内部核算统一用 **人民币 CNY**，汇率按月初固定汇率（避免天天变）。
2. **时间**：数据统计用**自然周（周一至周日）**，跨时区以目标市场当地时间为准。
3. **归因**：广告归因统一用平台的默认归因窗口，不自创模型。
4. **四舍五入**：金额保留 2 位小数，百分比保留 1 位。
