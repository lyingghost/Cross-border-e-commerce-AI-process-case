# 每日节奏（每人 5 小时）

目标：把 5 小时切成可预期的块，避免"忙了一天不知道忙了啥"。

## 时间块

| 时段 | 时长 | 做什么 | 不做什么 |
|---|---|---|---|
| **开工同步** | 15 min | 两人碰一下：昨天完成了什么 / 今天 3 件最重要的事 / 有没有卡点 | 不展开讨论，卡点留到下午 |
| **深度块** | 2 h | 自己干活：询价、改 Listing、拍素材、处理订单 | 不回消息、不给 Agent 下任务 |
| **Agent 块** | 30 min | 给 Agent 下今天的任务；审 Agent 昨天的产出 | 不陷入反复调 prompt |
| **执行块** | 2 h | 继续干活 + 处理 Agent 产出的落地动作 | — |
| **收工** | 15 min | 更新黑板状态、写 3 行日志、push 代码 | — |

## 开工同步模板（15 分钟，站着开）

```
【供给侧】
昨天：
今天 3 件事：
卡点：

【需求侧】
昨天：
今天 3 件事：
卡点：
```

超过 5 分钟没结论的话题 → 记下来，周五经营会讨论。

## Agent 块：怎么给 Agent 下任务

**三要素缺一不可**：

```
背景：我们在 [平台] 卖 [品类]，目前处在 Phase [X]，已经完成了 [Y]
约束：C1-C5（直接粘贴）
任务：具体要做什么，期望什么格式的产出
```

**反例**（会得到垃圾答案）：
> 帮我选个品

**正例**：
> 背景：我们在 TikTok Shop 美区做家居收纳，Phase 1，已完成竞品监控清单（20 个，见 data/output/phase1/competitors.csv）
> 约束：C1 首批 ≤¥3000；C2 不压货；C3 禁区类目除外；C4 每个建议要说清最坏情况；C5 方案周占用 ≤10 人时
> 任务：从差评中提炼 3 个产品改进机会，每个机会给出：涉及的差评原文、改进方案、预估增加的采购成本、供应商能否做到。用表格输出。

## 收工日志（3 行，写在腾讯文档"每日日志"）

```
今日完成：
今日发现（数据/认知上的意外）：
明日第一件事：
```

## 每日看的数据（Phase 2 起）

| 指标 | 阈值 | 超限怎么办 |
|---|---|---|
| 广告花费 | > 日预算 120% | 立即暂停，查原因 |
| ACOS | > 目标 × 1.5 | 降预算 + 清洗词 |
| 转化率 | 环比跌 > 30% | 查 Listing / 素材 / 近期差评 |
| 新增差评 | 任何 1–2 星 | 当天归因 |
| 库存可售天数 | < 14 天 | 触发 `stock.low` |

Phase 0–1 只需看**进度**（今天该做的事做了没），不看经营数据。
