# 每周经营会（周五，1 小时）

CEO Agent 在这个环节起作用（Phase 0–2 由人代行其职）。

## 议程

| 时段 | 内容 | 产出 |
|---|---|---|
| 0–10 min | **看数**：本周关键指标 vs 上周 vs 目标 | 指标快照 |
| 10–25 min | **审 Agent 产出**：本周各 Agent 给了什么，采纳了什么，为什么 | 采纳记录 |
| 25–40 min | **决策**：需要拍板的事（走 `decisions` 留痕） | 决策记录 |
| 40–55 min | **对齐下周**：每人 3 个目标，Agent 下周任务清单 | 下周待办 |
| 55–60 min | **流程优化**：这周什么事重复做了 ≥ 2 次？ | 新增/修改一条 SOP |

## 看数：每周固定看的 8 个数

Phase 0–1（还没开卖）看进度指标：

1. 本周投入人时（目标是 ≤ 50）
2. 候选组合 / 候选 SKU 数量变化
3. 完成的关键动作数
4. 卡点与未解决时长

Phase 2+（已开卖）看经营指标：

1. GMV / 净销售额
2. 订单数、客单价
3. 广告花费、ACOS、TACOS
4. 转化率（曝光→点击→下单）
5. 退货率、差评率
6. 单件净利 top3 / bottom3 SKU
7. 库存可售天数
8. 现金余额与未来 4 周支出预测

## 审 Agent 产出：四个问题

对每个 Agent 本周的产出问一遍：

1. **用上了吗？** 没用上的为什么 —— 是质量不行，还是我们没时间处理？
2. **数字对吗？** 抽检任意一个数字，人工复核。
3. **省时间了吗？** 如果不省，是这个 Agent 没用，还是我们用法不对？
4. **下次怎么更好？** 需不需要改 prompt、改输入、改 SOP？

把答案记进 `data/output/weekly/YYYY-MM-DD.md`。

## 决策记录模板

```markdown
## 决策：[主题]
- 日期：
- 假设：
- 证据：
- 结论：
- 最坏情况：
- 止损线：
- 复盘日期：
```

## 流程优化：这周重复做的事

每周至少找出 1 件重复做了 2 次以上的事，然后二选一：

- **能交给 Agent** → 写成 `workflows/*.md` 的一个流程
- **能模板化** → 存成模板，下次填空

> 这是整套系统能否越跑越轻的关键。跳过这 15 分钟，系统就会一直重。

## 每月一次： Agent 体检

- 算一次「Agent 净收益」= 节省的人时 − 协作花的人时
- 净收益连续两月为负的 Agent：**停用或重写**
- 净收益最高的 Agent：加大使用，考虑扩充它的职责
