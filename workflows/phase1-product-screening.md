# Phase 1 — 选品与供应链

> 触发条件：事件 `market.selected`
> 目标：筛出 3–5 个可测 SKU，找到能小批量供货的供应商
> Agent：Competitor, Product

---

## Step 1 — 建立竞品监控清单（Competitor，约 3 人时）

目标：20–30 个竞品，覆盖选定品类的 Top 3 价格带。

**给 Agent 的提示**：

```
我们在 [平台] 做 [品类]，目标市场 [市场]。
请建立竞品监控清单，要求：
- 数量 20-30 个，覆盖低/中/高三个价格带
- 每个竞品记录：名称、售价、评分、评价数、上架时间、卖家类型、主图风格
- 标注哪些是"可直接对标"的（同类同价位），哪些是"天花板"（我们要长成的样子）

输出：CSV 表格 + 一段观察总结（价格带分布、评分分布、共性卖点、共性差评）
```

产出：`data/output/phase1/competitors.csv`

---

## Step 2 — 从差评里找机会（Competitor + Product，约 3 人时）

**这是选品最高效的方法**：竞品的 1–3 星评价 = 用户明确说出来的未满足需求。

**给 Agent 的提示**：

```
分析上述竞品的 1-3 星评价（如果平台不开放，可用公开评论或第三方公开数据）。
请归类并统计频次，输出：
1. 差评原因 TOP 5（附出现频次与原文摘录）
2. 每一类差评对应的"产品改进方向"
3. 哪些改进我们能做到（成本可控、供应商可配合）
4. 哪些是行业通病（改不了，但可以在详情页提前说明以降低预期）

输出：差评归因表 + 3 个具体的产品改进机会
```

---

## Step 3 — SKU 批量筛选（Product，约 4 人时）

用选品评分卡对候选 SKU 打分，从 15–20 个筛到 3–5 个。

| 维度 | 权重 | 关键判断 |
|---|---|---|
| 毛利率 | 20 | 扣完全部成本后 ≥ 30% |
| 物流友好度 | 15 | 轻小、不易碎、非液体/带电 → 分数高 |
| 差异化空间 | 15 | 能否在材质/尺寸/配色/组合上做出区别 |
| 需求稳定性 | 10 | 长青需求 > 季节性 > 短期流行 |
| 竞争强度 | 10 | 头部评价数是 1000+ 还是 100+ |
| 供应链可得性 | 10 | 1688 是否有多家可选、能否 30 件起订 |
| 售后复杂度 | 10 | 是否易损、是否尺寸敏感、退货率高低 |
| 内容可塑性 | 10 | 是否"看得见效果"（短视频好拍） |

**给 Agent 的提示**：

```
基于竞品分析，列出 15-20 个候选 SKU，按上面的评分卡打分。
要求：
- 每个 SKU 给出 1688 上的大致拿货价区间（标注"估算"）
- 淘汰分低的，保留 Top 5，并说明为什么这 5 个值得打样
- 对每个 Top 5，写明"我们的差异化点"是什么

输出：完整评分表 + Top 5 卡片（每个一张：名称/差异化点/预估售价/预估毛利/风险）
```

产出：`data/output/phase1/sku-candidates.csv`（模板见 `data/templates/`）

---

## Step 4 — 单品利润精算（Product + Finance，约 3 人时）

对 Top 5 逐个精算。用 [`shared/kpi.md`](../shared/kpi.md) 的成本项清单，**逐项核对，不许漏**。

产出：`data/output/phase1/profit-model.md`，每个 SKU 一张表：

```markdown
### SKU-001 [名称]

| 成本项 | 金额(CNY) | 依据 |
|---|---|---|
| 售价 | | 竞品价格带中位数 |
| 货值 | | 1688 询价（30 件价） |
| 国内物流 | | |
| 头程 | | 重 g × 单价 |
| 关税/增值税 | | 税率 % |
| 平台佣金 | | % |
| 履约费 | | |
| 包装贴标 | | |
| **落地成本** | | |
| 广告费预留 | | 售价 20% |
| 退货损耗 | | 退货率 % × 单件损失 |
| 支付/汇兑 | | 3% |
| **单件总成本** | | |
| **单件净利** | | |
| **净利率** | | |
| **首批投入** | | 货值×数量 + 样品 + 素材 + 广告测试 |

```

**判定**：净利率 ≥ 15% 且 首批投入 ≤ ¥3,000 → 进入短名单；否则淘汰或重新谈价。

---

## Step 5 — 供应商询价与打样（人执行，约 8 人时）

这部分 Agent 只能辅助，必须人去做。

**Agent 能帮的**：生成询价话术、比价表、谈判要点清单。

**询价话术模板**（让 Agent 按 SKU 定制）：

```
您好，想咨询 [产品名]。
1. 30 件 / 100 件 / 500 件的单价分别是多少？
2. 是否支持定制 [差异化点]？定制的 MOQ 和加价是多少？
3. 能否提供样品？样品费与运费？下单后能否退还样品费？
4. 常规交期几天？30 件的交期呢？
5. 是否支持一件代发？代发价与代发邮费？
6. 能否提供产品图/视频素材？是否有专利或外观权？
7. 支持什么付款方式？能否先验货后付尾款？
```

**打样验收清单**：
- [ ] 实物与描述一致（材质、尺寸、颜色）
- [ ] 功能正常，无瑕疵
- [ ] 包装是否能扛住国际运输（做跌落测试）
- [ ] 拍照/拍视频效果是否好看（内容电商尤其重要）
- [ ] 有无异味、毛刺、安全隐患

产出：`data/output/phase1/supplier-shortlist.md`

---

## Step 6 — 触发下一步

短名单确定后：
1. 写入黑板 `product.shortlist`
2. 触发事件 `sku.shortlisted` → Store, Content, Finance 响应
3. 进入 Phase 2

## 检查清单

- [ ] 竞品监控清单 ≥ 20 个，覆盖三个价格带
- [ ] 差评归因完成，至少找到 3 个改进机会
- [ ] 15–20 个候选 SKU 已打分，选出 Top 5
- [ ] Top 5 单品利润精算完成，净利率 ≥ 15%
- [ ] 每个 SKU 首批投入 ≤ ¥3,000
- [ ] 至少 2 家供应商可小批量（≤ 50 件）供货
- [ ] 样品已收到并通过验收清单
- [ ] 触发 `sku.shortlisted`
