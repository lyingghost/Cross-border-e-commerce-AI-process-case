## 0. 前置结论：一条重要的坏消息

**小额免税（de minimis）已经彻底消失，这直接改变轻资产打法。**

| 时间 | 事件 |
|---|---|
| 2025-05-02 | 美国取消中国大陆/中国香港商品的 $800 免税 |
| 2025-08-29 | 扩大到**全球所有国家** |
| 2026-02-20 | 总统令确认继续暂停，并修订国际邮递关税 |
| 2026-05-02 | **T86 简易清关通道永久关闭**，所有 <$800 进口必须走正式/非正式报关 |
| 2026-06-24 | CBP 联邦法规落地，非邮政渠道暂停"无限期化"，推翻需国会立法 |
| 2026-07-01 | 欧盟取消 €150 免税，改为 **每件 €3 固定关税** + VAT，2026-11 起再加手续费 |
| 2027-07-01 | 美国 Section 321 对全部商业 shipments 正式废止 |

**这意味着什么**

- ❌ **"国内直发小包到海外消费者"模式基本判死**。每单都要报关 + 缴全额关税（中国货还叠加 301 关税），清关成本与时效都不可接受。
- ❌ 依赖直邮的铺货型玩法（eBay / AliExpress / 独立站自发货 / Amazon FBM）成本结构已被击穿。
- ✅ 轻资产只剩三条可行路径：
  1. **平台托管**（平台当进口商 + 平台履约，商家只供货到国内仓）
  2. **本地生产/本地履约**（POD、海外仓、本地仓）
  3. **零实物交付**（数字产品 —— 完全免疫关税与物流）

> 一句话：**0→1 阶段不要碰任何需要你自己报关的链路。**

## 2. Top 3 深度验证

### 🥇 #1 Etsy 数字下载（82 分）

| 维度 | 结论 |
|---|---|
| 需求 | 数字下载是 Etsy 成熟品类（计划表、婚礼/派对物料、墙贴、简历模板、Notion 模板等）。长青 + 强季节性（返校、圣诞、婚礼季） |
| 竞争 | ⚠️ **严重内卷**。同质化极高，新店无流量扶持 |
| 利润 | 边际成本≈0，无物流无关税无退货。售价通常 $3–15，几乎全是毛利 |
| 风险 | 版权风险（字体商用授权、IP 素材）；平台对 AI 生成内容有披露要求 |
| 人力 | **高度依赖设计/排版能力**。若两人都不具备，此项直接降到 60 分以下 |
| 现金流 | 回款最快，无备货压力 |

**最坏情况**：亏损 ≈ 0（只有时间成本）。做出 20–30 个 listing 仍零单 → 判定该赛道不适合，止损退出。
**多久能判断**：4–6 周（listing 数量 ≥ 30 且做过一轮 SEO 迭代后）。

### 🥈 #2 TikTok Shop 美区 全托管（81 分）

| 维度 | 结论 |
|---|---|
| 需求 | 美国是最大单一市场，内容电商仍在增长 |
| 门槛 | 保证金 **¥1,000**（远低于 POP 的 $1,500），企业或个体户执照均可 |
| 政策 | **90 天免佣金**，新商友好 |
| 职责 | 商家只供货到平台国内仓；定价、销售、物流、清关、售后**全部平台负责** |
| 现金流 | 公开案例：首年预算 $1,340–$6,140（对比 POP 的 $7,000–$26,500），**是进入美国市场资金效率最高的通道** |
| 风险 | ⚠️ **供应链能力审核是主要门槛**（需公司全景图、办公室图、仓库图、自有或外发工厂执照）。贸易型公司需准备外发工厂合作证明 |
| ⚠️ 关键限制 | **无定价权**。平台定零售价，毛利被压。我们的「净利率 ≥15%」目标在全托管下**不保证达成** |

**成本参考**（$25 售价的美区跨境单，公开案例拆解）：
平台佣金 6% $1.50 / 达人佣金 15% $3.75 / FBT 履约 $3.50 / 海运头程 $1.50 / 海外仓 $0.30 / 广告 $3.00 / 支付 $0.75 / FOB 成本 $6.00 → **净利 $4.70，净利率 18.8%**

**最坏情况**：¥1,000 保证金 + 首批备货 ¥3,000–9,000。若选品全错，货压在国内仓可转售或止损，实际损失可控在 **¥5,000–10,000**。
**多久能判断**：平台给流量，6–8 周可见分晓。
**定位**：**这是"验证选品手感 + 走通跨境链路"的通道，不是长期赚钱的生意。** 无定价权 = 无品牌资产。

## 3. 推荐与不推荐

### ✅ 推荐：双轨，但主力只有一条

**主力（80% 精力）：TikTok Shop 美区 全托管**
- 理由：de minimis 死后，"自己清关 + 自己履约"是最贵的环节，全托管把这两块完全交给平台；¥1,000 保证金 + 90 天免佣，是 2 人轻资产团队能进入美国市场的**唯一低资金通道**。
- 目标不是赚钱，是**用最小代价验证"我们选的品有没有人买"**。

**副线（≤20% 精力，仅在有设计/排版能力时做）：Etsy 数字下载**
- 理由：零库存零物流零关税，失败成本≈0，还能顺带练 SEO、标题、封面、用户洞察 —— 这些能力全托管练不到。
- **如果两人都没有设计能力，直接砍掉这条线**，不要为了"多一条腿"分散已经很紧的 50 人时/周。

### ❌ 明确不推荐

| 选项 | 原因 |
|---|---|
| 任何形式的国内直发小包 | de minimis 已死 + T86 关闭，每单报关成本击穿利润 |
| Amazon 美区自发货 / 小批量 FBA | 广告成本高 + 压货重 + 回款慢，不符合轻资产 |
| Temu 半托管 | 无定价权且持续压价，毛利 1 分 |
| 欧盟站点 | VAT 注册 + 每件 €3 关税 + 2026-11 起手续费 + GPSR 责任人要求，合规成本远超 0→1 阶段承受能力 |
| 同时开两个以上站点 | 50 人时/周撑不住，C5 硬约束 |

## 4. 30 天执行计划

| 周 | 动作 | 人时 | 产出 |

| W1 | 准备主体材料（营业执照/个体户、法人证件）；整理外发工厂合作证明、仓库图、办公室图；提交 TikTok 全托管入驻 | 8 | 入驻申请提交（审核 7–15 工作日） |

| W2 | 等审核期间：1688 询价（30 件价）、物流报价、头程报价 | 8 | 成本底表 |
| W2–3 | 选出首批 3 个 SKU，按 C1（≤¥3,000/SKU）下单备货 | 6 | SKU 清单 + 利润测算 |

| W4 | 复盘：出单率、退货、平台结算价是否覆盖成本 | 4 | Phase 0 复盘报告 |
