# 数据管理

## 分层

```
data/
├── raw/        原始导出 / 抓取数据，只读不改
├── output/     各阶段 Agent 与人工的产出
│   ├── phase0/
│   ├── phase1/
│   └── weekly/
├── templates/  空白模板，复制后使用
└── blackboard.json   共享黑板（Phase 0–2 由人维护）
```

规则：
- `raw/` 里的文件**永不修改**，处理时复制到 `output/` 再改
- `output/` 按阶段分目录，文件名带日期：`20260912-market-scan.csv`
- 涉及成本、供应商报价的原件**不进仓库**，放腾讯文档

## 接入计划（0→1 阶段：不花钱）

| 数据 | 现在怎么拿 | 什么时候升级 |
|---|---|---|
| 平台类目与竞品数据 | 平台前台人工看 + 截图 | 出首单后考虑付费工具 |
| 搜索量/趋势 | Google Trends、平台热榜、站内搜索下拉词 | 同上 |
| 货源与报价 | 1688 人工询价 | 稳定后建供应商库 |
| 物流报价 | 货代询价 + 平台运费计算器 | — |
| 汇率 | 手动记月初固定汇率 | — |
| 销售与广告数据 | 平台后台导出 CSV | Phase 2 起每周导出 |

> 原则：**先用手能拿到的数据做决策，验证出单后再为数据付费。**
> 0→1 阶段买工具的 ROI 几乎必然是负的。

## 导出频率

| 数据 | 频率 | 谁负责 |
|---|---|---|
| 平台销售报表 | 每周一导出上周 | 需求侧 |
| 广告报表 | 每日看 / 每周导出 | 需求侧 |
| 竞品价格与排名 | 每周 | 供给侧 |
| 评价与退货 | 每周 | 需求侧 |
| 汇率与物流报价 | 每月 | 供给侧 |

## 数据质量三原则

1. **标注来源**：每个数字旁边写清是哪来的。估算的写"估算 + 依据"。
2. **保留单位**：金额写 `¥1,234` 或 `$12.34`，别只写数字。
3. **不删历史**：即使发现数据错了，也不要覆盖 —— 新建一版，注明修正原因。
